RESEARCH USE & LIMITATIONS

Interpret results with care.

  • Live inference requires trained model files generated from the original experiment feature matrix.
  • Verify feature parity against the training NPZ before treating predictions as research-valid.
  • The seam-carving simulator is a reference implementation; verify equivalence with the exact dataset-generation library and parameters.
  • Paper-reported benchmark values are separate from live predictions.
